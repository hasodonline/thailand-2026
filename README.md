## 🔧 איך בונים מחדש


**מה ההבדל בין הגרסאות:** קודי ההזמנה ושם המשפחה יושבים ב-`site/private-refs.json`
(לא ב-git). הבנייה הפרטית מזריקה אותם; הציבורית שמה `••••••` במקום.
